# RomDoc MVP

## Goal

Build a multilingual healthcare directory and appointment platform for Romania.

## Languages

- Romanian
- English

## User Types

### Visitor

- Search doctors
- Browse specialties
- Browse cities
- View doctor profiles
- Submit appointment requests

### Doctor

- Login
- Manage profile
- Manage availability
- View appointment requests

### Admin

- Manage doctors
- Manage clinics
- Manage specialties
- Approve reviews
- Approve doctor accounts

## Phase 1

- Authentication
- Doctor directory
- Doctor profile pages
- Search
- Romanian/English support
- Appointment requests

## Phase 2

- Payments
- Calendar sync
- AI translations
- Advanced search
- Clinic subscriptions
